# @freellm/web (placeholder)

The admin UI scaffold lands in **Group 2**. Per the project-level `CLAUDE.md`:

- **Design language**: invoke the `ui-ux-pro-max` skill on the first UI tick to fix a palette + type scale and write `src/design-tokens.ts`.
- **Baseline reference**: pick one of `linear.app` / `vercel` / `stripe` from `your design system reference`.
- **Main components**: React Bits (https://github.com/DavidHDev/react-bits) — Hero, Card, Background, Magic-UI / Aceternity-style motion bits.
- **Base controls**: shadcn/ui restyled with our design tokens (no default look).
- **Charts**: recharts. **Icons**: lucide-react. **Animation**: Framer Motion.

Pages required: Landing · Dashboard · Models · Routing Lab · Virtual Keys · Providers · Logs · Settings — each with full loading / error / empty / success states, search/filter/sort, and detail drawers.

Do not start writing the web app before Group 2 — Tick 5 closes the backend surface.
